# Credits and contribution boundaries

This is an independent downstream serving benchmark. It does not claim upstream participation, review or endorsement.

- **Niko1221 and the Strata contributors** created [Strata](https://github.com/Niko1221/Strata): the inference engine, resident INT8 cache, batching/speculation, GDN/attention and prompt kernels, tokenizer/chat template, API wrapper and vision integration. The selected stock engine is 0.1.56 at `06698c674673008395ba6e971580538d6b1ea6e0`. The official 0.1.50 baseline and pure prompt-preparation helpers are based on `1aff6d14117b88171fcfcec8f2b55fdc47f2b165`. The API tests deliberately retained the deployment's 0.1.42 wrapper. These versions have different roles, recorded in [DEPENDENCIES.md](DEPENDENCIES.md). Strata's [MIT notice](LICENSES/Strata-MIT.txt) remains applicable.
- **The Qwen team** created [Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next) and its MTP model. **ISTA-DASLab** supplied the GSQ/RCO quantization methods and original quantized GGUF shards. **alesha-pro** packaged the unchanged quantized shards and extracted the separate control vector; **huihui-ai** supplied the abliterated checkpoint from which that direction was derived. Base-model, quantization, checkpoint and packaging contributions are distinct. Exact retained revisions and asset hashes are in [DEPENDENCIES.md](DEPENDENCIES.md).
- **The llama.cpp/ggml, NVIDIA CUDA/CCCL, Python, Jinja2, regex, Pillow and other dependency contributors** supplied underlying model tooling, runtime components and prompt/image preparation support. Their notices and terms remain their own; the vendor bundles are not redistributed here.
- **The repository maintainer** supplied project direction, hardware and publication. **Codex sessions and collaborating agents** prepared the isolated official bundles, verified signatures and asset identities, wrote the bounded benchmark/API/mixed-load collectors and CPU tests, generated fictional fixtures, retained collector failure/correction evidence, compared supported serving settings and assembled the measured results. Those are work roles, not extra human authors or claims of ownership over upstream code or methods.

The new work is measurement, setting selection, guarding, fixture construction, collector validation and evidence packaging. It is not a new inference algorithm. No LSA selector/maps/runtime were used in this campaign. An earlier LSA working tree supplied only byte-identical upstream pure Python tokenizer and chat-template code for prompt preparation; its filesystem location did not make LSA a runtime dependency.

Input ledgers and task prompts were fictional/synthetic experiment material. Model answers are retained as observed outputs, including failed arithmetic answers, under the applicable model/output terms. No staff conversations, client documents or private workpapers were used as benchmark inputs. The Apache source/fixture grant is described in [LICENSE.md](LICENSE.md); it does not relicense model-derived responses.

The measured gains apply to the same-day matched controls, hardware, custom IQ3_S/control-vector configuration and finite workloads described in [RESULTS.md](RESULTS.md). There is no general quality-equivalence, longer-context or production-deployment claim.
