# Public upstream provenance

Publication staging copies the small official signed feed, feed signature, component manifest, engine BUILD, Control BUNDLE and pinned public update keys here from the verified vendor packages. No vendor binary or large package archive is republished. The original upstream URLs and hashes are in the preparation/verification receipts.

The tested Linux CUDA engine is official0.1.56, build06698c674673+cuda13.0. The official0.1.56Control package was downloaded and verified for inspection only. API validation retained the installed0.1.42wrapper and its existing recovery behavior. The newer Control was not used to produce the API results.

These files retain their upstream notices and signatures. Check PUBLICATION-MANIFEST.json for source/public byte identities; operator-path redactions apply to local research receipts, not a new vendor-signature claim.
