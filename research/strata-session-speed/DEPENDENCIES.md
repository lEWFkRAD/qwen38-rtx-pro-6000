# Dependencies and reproducibility boundaries

This package records a bounded live API measurement and a request-local confidence screen. It is **not a turnkey installer or a production-management tool**. It contains no serving configuration, credential, model weight, vendor executable or runtime library. Public source retains the experiment's structure, but operator paths and the five private integrity pins are replaced with roles; adapt an equivalent authoritative guard before running it elsewhere. Do not bypass those guards to make a public copy run.

The serving runtime is the already deployed official **Strata engine 0.1.56**, source [`06698c674673008395ba6e971580538d6b1ea6e0`](https://github.com/Niko1221/Strata/tree/06698c674673008395ba6e971580538d6b1ea6e0), official decoder SHA256 `21cb8dd0c744c84176a019ef3cfebd27997968f211b197429df897cc6af92788`, with matched vision/CUDA libraries and retained Python/API wrapper **0.1.42**. The official source's `src/program/generate.cpp` SHA256 is `3ab400c6885981566e49e6a62b34ac9a79916b161382b91d30977cbe9e88aa05`. Vendor asset download/signature provenance and model dependencies are documented in the [stock package](../strata-0156-tuning/DEPENDENCIES.md); the subsequent approved 262K capacity profile and its limited qualification are recorded in the [context package](../strata-context-262k/DEPENDENCIES.md). No native source build or weight training is part of this speed experiment.

The fixed serving allocation is eight 262144-token slots, ordinary fully resident INT8 KV, all 24576 GPU-resident experts, matched vision and prefill 8192. The custom IQ3_S model, MTP/prompt lookup, vector strength 1.0 at layers 4–44/project/per-layer and fused serving environment are retained. Sampling and `experimental_speed_projection=true` are inherited. The confidence screen sends only the top-level request override `strata_tune.spec_min_p`; it does not change startup depth, sampling, projection, residency, model or server configuration. Official-source inspection shows this override applies to solo generation; continuing batch slots use the startup floor, so native-slot migration invalidates a solo confidence comparison.

The collectors reuse these earlier downstream modules rather than embedding a second production guard:

- The retained [production canary](../strata-0156-tuning/promotion/production_canary.py) supplies the normal authenticated, process-bound `Guard`, readiness helper loader and bounded JSON request function. The historical operator source path differs from this published relative path.
- Its [API helpers](../strata-0156-tuning/api_canary.py) and [benchmark helpers](../strata-0156-tuning/benchmark_strata.py) provide pure tokenizer/template preparation and earlier fixture utilities. Only these pure prompt helpers are used from the historical LSA checkout; no LSA maps, kernels or inference runtime are involved. Their unchanged upstream tokenizer/template basis and source pin `1aff6d14117b88171fcfcec8f2b55fdc47f2b165` are documented in the stock package.
- The private installed readiness-contract adapter and baseline integrity records are deliberately omitted. A deployment owner needs its own equivalent adapter and private pins. The public placeholders fail closed.
- [The earlier publication normalizer](../strata-0156-tuning/publication/stage_publication.py) supplies shared text/JSON privacy normalization. This package's additional report projection removes probes, identities, private pins, runtime paths and raw generated text. The stager never accesses production, mutates Git, commits or uploads.

Python 3 and the retained wrapper's dependencies are needed. Tokenizer/template preparation uses the matching tokenizer assets plus upstream Python/Jinja2/regex helpers; system guard adapters also depend on their own Linux process/service interfaces and `nvidia-smi`. A complete portable Python environment lock is not supplied. The public synthetic fixture files preserve full messages, prompt counts, tokenizer hashes and token-sequence hashes; the model tokenizer itself must be obtained separately under its terms.

Source and published hashes in the publication manifest distinguish exact local artifacts from normalized public copies. Original failed report statuses are preserved, and archived collector revisions are separate from later corrections. Synthetic model answers are observations, including incorrect arithmetic; matching hashes do not establish correctness. Retained model assets and generated answers remain subject to their applicable upstream/model/output terms, including the Qwen Community License 1.0 identified by the retained package.
