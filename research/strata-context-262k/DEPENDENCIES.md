# Context-test dependencies

This package records an isolated November 3, 2026 context experiment. It is not a turnkey installer or permission to stop a server. Vendor binaries, model weights, actual serving configurations and private ownership snapshots are not distributed here. Example paths such as `/srv/context-test/engine`, `/srv/context-test/prompt-source`, `/srv/context-test/tokenizer` and `/srv/context-test/evidence` name roles on the reader's own machine.

## Same official engine and retained API

The decoder is the already qualified official **Strata 0.1.56**, build `06698c674673+cuda13.0`, source [`06698c674673008395ba6e971580538d6b1ea6e0`](https://github.com/Niko1221/Strata/tree/06698c674673008395ba6e971580538d6b1ea6e0), from [app release v0.2.10](https://github.com/Niko1221/Strata/releases/tag/v0.2.10). Its SHA256 is `21cb8dd0c744c84176a019ef3cfebd27997968f211b197429df897cc6af92788`.

Use its matched official vision executable and CUDA 13 libraries. The [pinned engine archive](https://github.com/Niko1221/Strata/releases/download/v0.2.10/strata-engine-0.1.56-linux-x86_64-cuda-cuda13.tar.gz) is 667,699,126 bytes, SHA256 `df6a6dfd806289caa42becd2acc14081815bedac9ec8f5efa3821a7d10582ee5`; matched vision SHA256 is `bf6c2a1ae8a33100cc9afb6d44c83f893d6ae5d2ab5d1ff17095d9059adc729b`. Signed feed/component verification, public keys and full library identities are retained in the [stock benchmark dependency/provenance record](../strata-0156-tuning/DEPENDENCIES.md). These bundles are not reuploaded with the context tests. No engine compilation occurred.

API tests retain **Python/API wrapper 0.1.42**, including its existing compatibility/recovery behavior. The public source basis is [`61b3fb5dd3f1e8ec09cf7e4e05208bc6d3c46406`](https://github.com/Niko1221/Strata/tree/61b3fb5dd3f1e8ec09cf7e4e05208bc6d3c46406); see the [earlier runtime provenance](../../strata-c8/DEPENDENCIES.md). Prepared Control 0.1.56 was not the measured API runtime. The isolated test changes its private child context/residency/slot/prefill settings, not the installed production wrapper or model assets.

The hardware is one RTX PRO 6000 Blackwell 96 GB on Linux x86-64, driver 615.71.09, retaining the 550 W policy. Context requests use ordinary INT8 KV with `--max-context 262144 --kv-resident 262144`, required full 24,576-expert GPU residency and the established fused serving environment. Tested native shapes are 4 slots/prefill 32768, 8/prefill 16384 and 8/prefill 8192. There are no RoPE/YaRN argument overrides. These requested shapes do not by themselves establish quality, full API residency or concurrent deep decoding; completed observations and rejected attempts must be read separately.

## Prompt preparation and frozen synthetic data

The pure `Tokenizer` and `ChatTemplate` helpers are byte-identical to [Strata 0.1.50 source `1aff6d14117b88171fcfcec8f2b55fdc47f2b165`](https://github.com/Niko1221/Strata/tree/1aff6d14117b88171fcfcec8f2b55fdc47f2b165). Helper hashes are recorded in the fixture metadata and the [stock dependency record](../strata-0156-tuning/DEPENDENCIES.md). An old LSA working-tree path was only a filesystem location for these pure Python helpers. No LSA selector, map, native research build, PyTorch or Triton is required by this context campaign.

The builder ran with Python 3.12, `regex` and Jinja2 from the retained environment. Pillow creates the synthetic image used by API smoke checks. A complete new environment lock is not supplied. The exact model tokenizer/template files must match the frozen metadata hashes; substitute versions define another experiment.

The authoritative full input is `long-context-deep8-fixtures.json.gz`, with its independent `long-context-deep8-fixtures-oracle.json`. It contains one 259,999-token tail-marker document and eight distinct 251,764–251,835-token documents with five opaque requested seals each. Seal values occur once in their own prompt and nowhere in another slot document. Expected answers are independently parsed from literal records, rather than inferred from token positions. The preliminary two-case fixture is retained as a superseded draft, not measured nine-case evidence. `api-long-case.json.gz` preserves the exact standalone long API input.

Public gzip files have `mtime=0` and no stored filename; the publication manifest records original source, normalized uncompressed and compressed SHA256 values and Python/zlib identities. Decompress the JSON before passing it to a harness. To regenerate new data, use `build_long_fixtures.py` with the clean pinned helper checkout, matching tokenizer assets and `--deep-slots 8`; changing seeds/data consumes a different test set.

The API load helper changes the system/continuation instructions to elicit long output. Its source records prompt hashes, output allowances, any requested EOS policy, priming and observed live-slot conditions. That capacity/load screen is distinct from ordinary exact-response retrieval. Preserve each attempt's source and declared scope; do not apply a later helper's criteria retroactively.
